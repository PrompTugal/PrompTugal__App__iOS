## What the editor changed on this site

- **PrompTugal only.** The product pages and the footer no longer name or link the other sites. The validator now refuses a product page that names another brand. Host names in code blocks (on the privacy page) are allowed, because a privacy page has to name the hosts the app talks to.
- **Two products.** New pages for readers and for teams, a features page and a plans page (team packs, supporter tier, sponsor slots, no prices).
- **Features follow the code.** Each feature in `website/features.json` lists the files and the screens that prove it. It shows as "In the beta" only when all of them are on `dev`, and a screen counts only when it has a real view, not a placeholder. The validator refuses a page whose label disagrees.
- **Admin pages generated at build time:** a push dashboard from the status pages, a screens page from `Destinations.swift`, release history from the git tags, a CI page from the workflow files, and this build log.
- **The deploy fetches full history**, so the release page can read every tag.
