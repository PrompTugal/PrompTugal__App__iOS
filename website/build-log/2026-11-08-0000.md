## What changed in the checks

- **A feature is in an app only if that app is built from its files.** `website/admin.py` reads `apps.json` for the folders of each app and the packages it links, and looks for a feature's files there. Test folders never count. Before `apps.json` and the app folders exist, the old `PrompTugal/` folder is the app, so tonight's labels stay true.
- **`features.json` names files, not paths.** `**/ScheduleStore.swift` finds the file whether it is in `PrompTugal/Schedule/` or in a package. Reader features are checked against the PrompTugal app, team features against the Team app. Sample data and reading credit moved to the team list.
- **The push dashboard reads `split/*` branches** as well as `night/*`, so the three-apps status pages show up the way the earlier packs' did.
- **Facts about the public app** (version, build, bundle ID, website list, icon) are read from `Apps/PrompTugal/` once it exists, and from the old project until then.
