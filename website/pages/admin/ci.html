Continuous integration

Nobody on the team can compile Swift on Linux, and most of the code is written by agents on Linux. So CI is the compiler: every branch is built and tested on a Mac in GitHub Actions, and a red branch is not merged.

Two jobs for two things

  • The app. The iOS workflow runs on every push to a night/* branch and to dev, and on pull requests. It tests the vault package with swift test, builds the app for the simulator without signing, and runs the unit tests on an iPhone simulator. A failure puts the compiler error in the job summary, so a session can read it through the GitHub tools.
  • The release and this site. The release workflow runs on every push to dev. It bumps VERSION, tags the release, then tests, builds and validates this site and deploys it to GitHub Pages. The deploy is only done when the live version.json serves the new release.
