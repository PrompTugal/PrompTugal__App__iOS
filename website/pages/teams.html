How it works

Public data, private vaults

  • What the team publishes, the app reads. The dashboards are built from JSON the team’s site already publishes: the people, each person’s tasks and decisions, the stand-up briefings, and the agents’ wakes, reports, pulse and log. The app caches it, so it works offline.
  • What is private stays encrypted. Notes, messages and shared picks go into vaults. Each file is encrypted on the device before it leaves; the server holds ciphertext. Only people with the vault’s keys can read it.
  • iPad first. The iPad has room for a sidebar and a dashboard side by side. What works well there goes back to the website.
  • Everything is visible. Debug mode shows every request the app makes, its size and timing, every vault read and decryption step, and which keys exist on the device, never their values.
